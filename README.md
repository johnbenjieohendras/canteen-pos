# Mini Canteen Cashiering and Back Office System

A PHP and MySQL-based canteen management system designed for
cashiering, inventory management, sales monitoring, and reporting.

## Features

- User login and role management
- Cashier POS
- Product management
- Category management
- Inventory management
- Stock-in and stock history
- Sales tracking
- Expense management
- Sales reports
- Receipt printing
- Audit logs

## Technologies

- PHP
- MySQL / MariaDB
- HTML
- CSS
- JavaScript
- Bootstrap
